This research repository documents two experiments examining whether similarity in participants' eye movements while viewing narrative movies predicts later recognition memory performance.

## What is documented

- [Study design](study-design.md): participants, apparatus, stimuli, and the distinction between Study 1 and Study 2.
- [Eye-tracking preprocessing](eye-tracking-preprocessing.md): movie alignment, trimming, invalid-sample handling, interpolation, pixel conversion, and merging.
- [Synchrony and GLMM analysis](synchrony-and-glmm.md): segment matching, pairwise correlations, IGS/GS construction, and trial-level mixed-effects models.
- [Reproducibility notes](reproducibility.md): software, code provenance, known documentation/code differences, and files still to be deposited.
