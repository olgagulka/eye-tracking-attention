# Notebooks

The notebooks in this directory are preserved analysis records. They were copied byte-for-byte from the supplied source files and have not been refactored, cleaned, or converted into new scripts.

## Organization

- [`preprocessing/preprocessing_Eyetracking.ipynb`](preprocessing/preprocessing_Eyetracking.ipynb): eye-tracking preprocessing, quality checks, fixation processing, merging, resampling explorations, and heatmap explorations.
- [`analysis/synchrony_visualization.ipynb`](analysis/synchrony_visualization.ipynb): segment-level pairwise gaze correlations, individual and group synchrony, GLMMs, average marginal effects, and manuscript visualizations.

The notebooks include hard-coded paths and participant/movie settings from the original analysis environment. They also contain historical and exploratory cells alongside sections labeled as current or final. They should therefore be read with the workflow documentation rather than assumed to run sequentially from the first cell to the last.

Scripts described in the research notes but not yet supplied are listed in the [reproducibility notes](../docs/reproducibility.md#files-still-to-be-deposited).
